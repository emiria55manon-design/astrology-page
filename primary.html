PRIMARY DIRECTIONS

地球が一回りする時間を、人生の年に：
プライマリー・ディレクション

空は1日に1回転します（第一運動）。出生のとき、東の地平線にのぼっていた点（ASC）や、いちばん高い点（MC）に、ほかの天体が、空の回転で、あとどれだけ回ると着くのか。その「回る角度」を「年」に読み替えるのが、プライマリー・ディレクションです。

考え方：空が1°回る = 人生の1年

第一運動（空の回転・1日に360°）
→ プライマリー：回った角度を年にする。
1°回る = 約1年

天体が黄道を東へ進む動き（第二運動）を使う技法は、セカンダリー・プログレッションのページで説明しています。

プトレマイオス式：回転1° = ちょうど1年
ナイボッド式：回転0.9856° = 1年
0.9856°は、太陽が1日に東へ進む平均の角度です。

「なぜ1°が1年なのか」は、天文学の根拠ではなく、占星術の約束事です。このページは、空の回転の角度と年の対応を見せるものです。計算方法には流派があり、ここでは、いちばん素直な見かた（天体そのものの日周円が、4つの角に着くまでの回転角）だけを扱います。

このページで見せるのは「合」だけです

有名なサイトやソフトの一覧には、天体が角（ASC・MC）に、合（0°）だけでなく、60°・90°・120°・180°のアスペクトで着くときも、たくさん並びます。天王星・海王星・冥王星、ノード、順方向と逆方向の両方も入るので、行数が多くなります。

このページは、「空が回って、天体が角に着く」しくみを、見て分かることを目的にしています。そのため、順方向・逆方向の、天体が角に重なる「合」だけを図にしています。専用ソフトで、黄緯を使わない設定（ゾディアカル）にしたときの合の行は、ほぼ一致します（初期設定の、黄緯なしの点で計算）。黄緯を使う設定（ムンデン）のソフトとは、図の上の「天体の黄緯を使う」にチェックを入れると、ほぼ一致します。黄緯を使うと、4つの角のどの行も動きます（月は数年、ほかの天体は数か月〜2年ほど）。アスペクトの行は、ここには出ません。

生年月日と出生地を入れる

入力のしかた（開く）
  1. 生年月日：西暦で入れます（1850〜2050年）。
  2. 出生時刻：24時間表記で、分まで入れます（午後1時53分なら、13:53）。時刻が1分ずれると、着く年齢が約3か月ずれるので、母子手帳などの記録で、確かめてください。わからないときは、「出生時刻がわからない」にチェックします。
  3. 出生地：日本の県庁所在地は、プルダウンから選べます。それ以外の場所は「その他」を選んで、緯度と経度を入れます。
  4. 時差：その土地の標準時です。日本は「日本（UTC+9）」のままで大丈夫です。夏時間は使いません。
  5. 緯度・経度：「度・分」ではなく、小数の度で入れます。「度＋分÷60」で換算します。
    例：北緯34°23′ → 34＋23÷60 ＝ 34.3833　／　東経132°26′ → 132＋26÷60 ＝ 132.4333
    北緯・東経は＋、南緯・西経は−（マイナス）をつけます。
  6. ほかのソフトと比べるとき：生年月日・時刻・緯度・経度・換算（1°＝1年）を、そろえます。このページの「天体の黄緯を使う」は、ソフトの設定に合わせます。ソフトが「黄緯なし（ゾディアカル）」ならチェックなし、「黄緯あり（ムンデン）」ならチェックありです。行によって両方が混ざるソフトもあり、月は差が大きく出ます。ASC・MCへのオポジション（☍）の行は、このページの、DSC・ICの行に当たります。

入力した内容は、この画面の中だけで計算されます。送信も保存もしません（「覚えておく」にチェックしたときだけ、この端末のブラウザに残ります）。プライマリーは、出生時刻と出生地で結果が大きく変わります。出生時刻が1分ずれると、約0.25年（3か月ほど）ずれます。夏時間は使わず、その土地の標準時で入れてください（夏時間で記録された時刻は、1時間引いて入れます）。

図の見かた：空が回るので、ふつうの空と同じく、天体は東（左）からのぼり、いちばん高い所（上）を通り、西（右）にしずみ、下の方（IC）へ回ります。生まれたときに東の地平線にいた天体は、ASCの位置から始まります。4つの角は、図の中で動きません。角の横の、サイン・度数・ハウスは、出生図のものです（ハウスは、ASCのサインを1ハウスとするホールサイン）。天体が、角の線に重なったときが、「角に着いた」ときです。

詳しい注意・用語・精度（開く）
  • ここで求めているのは、天体そのものが、1日に1回転する円の上を、ASC・MC・DSC・ICの4つの角まで回る角度です。これは、プライマリー・ディレクションの基本の考えかたの1つですが、実際の技法には、天体を黄道の度数に置き換えて測る方法、黄緯を使わない方法、「ディレクトする点」と「受ける点」を逆にする方法など、いくつもの流派があります。流派によって、年齢は数か月〜数年変わります。
  • MC・ICに着く角度は、赤経の差そのものです。ASC・DSCに着く角度は、その天体の赤緯と出生地の緯度から出る、昼の半円の長さ（半日周弧）を使っています。初期設定では、天体は、黄道の上の点（黄緯0°）として扱っています（図の上の「天体の黄緯を使う」で切り替えられます）。ソフトによって、黄緯を使うかどうかの設定が違います。
  • 位置は、astronomy-engine（高精度の暦のライブラリ）で計算した、地球の中心から見た視位置です（光行差・章動・光行時間を含みます）。ライブラリを読み込めないときだけ、NASA（JPL）の近似軌道要素と、簡易な月の式に切り替わります（木星・土星は最大10′ほど、月は最大6′ほどずれます）。月の視差や、大気による屈折は入れていません。
  • 黄緯の切り替え：「天体の黄緯を使う」にチェックすると、天体の実際の位置（黄緯を含む赤経・赤緯）で、4つの角に着く角度を測ります。専用ソフトの「ムンデン（mundane）」の行に当たります。チェックなしは、黄道の度数で測る「ゾディアカル（黄緯なし）」の行に当たります。
  • 順方向（ディレクト）は、空の回転と同じ向きに回します。逆方向（コンバース）は、逆向きに同じだけ回します。着く年齢は、逆方向のとき「360°−順方向の角度」になります。ここでは「空を逆向きに回す」方式です。本やソフトによって、定義の言い方が違うことがあります。
  • 用語：赤経＝天の赤道に沿って測る、天球の経度。赤緯＝天の赤道からの、天球の緯度。黄緯＝黄道からの角度（初期設定では0°にしています。切り替えで、実際の値を使えます）。半日周弧＝天体がのぼってから、いちばん高い所に着くまでに、空が回る角度（ASC・DSCに着く角度に使います）。プレドミネーター・アルコクデン＝寿命の計算に使う、生命を代表する天体と、年数を配る天体です（このページでは扱いません）。
  • 扱っていないもの：天体が角に重なる（合）ときだけを扱います。60°・90°・120°・180°のアスペクトに着くときや、天王星以遠・ノード、寿命計算（プレドミネーター・アルコクデン）は入っていません。専用ソフトの一覧は、これらを含むので、行数が多くなります。
  • 出生時刻が、とても大切です。時刻が1時間ずれると、着く年齢は約15年ずれます。時刻がわからないとき（正午として計算）の年齢は、参考になりません。
  • サイン・度数・ハウス：4つの角と、7つの天体の出生図での位置を、黄道のサインと度数で出しています（天体は黄緯0°の点）。ハウスは、ホールサイン方式（ASCのあるサイン全体が1ハウス）です。図の円は、空の回転を見せるもので、黄道のサインの輪ではありません。
  • 年齢は、満年齢の小数で表しています。暦の年月は、出生から、年齢×365.2422日後です。
  • 歴史的な由来（だれが、いつ、どの換算を用いたか）は、このページでは確認していません。
  • 占い・鑑定の結果ではなく、仕組みの説明のための図です。
